# Glossary · Frontend UI

人 ⇄ Agent 对齐前端界面用语。领域业务词仍以根 `CONTEXT.md` 为准。

| 界面用语 | 含义 | 代码锚点 |
|----------|------|----------|
| **侧栏 / Sessions** | 会话列表与新建会话 | `#sidebar` · `#conversationList` |
| **主对话区** | 消息流渲染区 | `#conversationView` · `#chatStage` |
| **作曲栏 / Composer** | 输入框与发送 | `.composer-section` |
| **快捷提问** | 预置 prompt 按钮 | `#quickPrompts` |
| **模型徽章** | 顶栏当前模型提示 | `#modelBadge` |
| **模型设置** | BYOK / 后端地址弹窗 | `#settingsButton` |
| **主题切换** | 明暗对比主题 | `#themeToggle` |
| **面试助手品牌** | 侧栏 `[面试助手]` | `.brand` |

Showcase 推荐路径见根 `README.md` §Showcase。
