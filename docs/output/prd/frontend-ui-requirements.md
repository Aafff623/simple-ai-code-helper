# AI Code Helper · 前端界面功能需求

> 用途：交付给 GPT 生成高级前端 UI 工程。本文档定义功能要点、界面要素、按钮、交互、状态与交付物。GPT 据此产出可运行前端，打包 zip 返回。

## 1. 项目背景

AI Code Helper 是一个 AI 编程面试助手后端（Spring Boot + LangChain4j + 阿里云百炼 Qwen 大模型）。前端为对话式交互界面，用户与 AI 助手围绕编程学习与求职面试进行流式对话。

助手人设（来自系统提示词 `system-prompt.txt`）：编程领域小助手，聚焦 4 个方向：
1. 规划清晰的编程学习路线
2. 提供项目学习建议
3. 给出程序员求职全流程指南（简历优化、投递技巧）
4. 分享高频面试题与面试技巧

## 2. 后端 API 契约

唯一对外接口：

```
GET /ai/chat?memoryId={int}&message={string}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| memoryId | int | 是 | 会话标识，相同 ID 共享上下文记忆（最近 10 条） |
| message | string | 是 | 用户消息，需 URL 编码 |

返回：`text/event-stream`（SSE）。每个 event 的 `data` 字段是 AI 回复的一个文本块，逐块推送，分块粒度不固定，前端需顺序拼接。

关键约束：
- 流式接收：用 `EventSource` 或 `fetch` + `ReadableStream`，逐块拼接到当前 AI 消息。
- 会话隔离：不同 `memoryId` 记忆独立。前端为每个会话生成并管理 `memoryId`（建议自增整数）。
- 护轨拦截：若 `message` 命中敏感词（如 `kill`/`evil`），后端会以非正常流终止（error）返回。前端识别流 error 后提示"输入被安全护轨拦截"。
- 无鉴权：当前无登录，无 token。
- 无历史接口：后端不提供历史消息查询。会话历史只能由前端在 `localStorage` 按 `memoryId` 持久化，切换会话时从本地恢复。
- 跨域：后端已全局开启 CORS（允许所有源、方法、头，带 credentials），前端可直接调用或走 dev server 代理。

## 3. 技术栈建议

- 框架：React 18 + Vite（优先）或 Vue 3 + Vite
- 流式：`EventSource`（GET 天然适合）
- Markdown 渲染：`react-markdown` + `remark-gfm` + 代码高亮（`prismjs` 或 `shiki`）
- 样式：Tailwind CSS
- 状态：Zustand（React）或 Pinia（Vue）
- 持久化：`localStorage`（会话列表 + 各会话消息历史）

## 4. 界面布局

桌面三栏式，移动端单栏自适应。

```
┌───────────┬───────────────────────────────┐
│           │  顶部栏（助手名 · 主题切换）    │
│  侧边栏    ├───────────────────────────────┤
│  会话列表  │                               │
│           │       对话区（消息流）          │
│  + 新会话  │                               │
│           │                               │
│           ├───────────────────────────────┤
│           │  快捷方向 · 输入区 · 发送       │
└───────────┴───────────────────────────────┘
```

### 4.1 侧边栏（会话管理）

要素：
- 顶部 Logo + 助手名："AI 编程面试助手"
- 「+ 新建会话」按钮：生成新 `memoryId`，清空对话区，进入空白会话
- 会话列表：每项显示会话标题（取首条用户消息前 16 字）+ 相对时间；点击切换；当前会话高亮
- 每个会话项 hover 出「删除」按钮（仅前端移除，后端无删除接口）
- 底部：版本/状态信息（可选）

状态：
- 无会话时显示欢迎引导

### 4.2 顶部栏

要素：
- 助手名 + 副标题（"编程学习 · 求职面试 · AI 助手"）
- 右侧：「深色/浅色主题」切换按钮
- 可选：「清空当前会话」按钮

### 4.3 对话区（消息流）

消息类型：
- 用户消息：右对齐气泡
- AI 消息：左对齐，支持完整 Markdown 渲染（标题、有序/无序列表、代码块语法高亮、表格、链接、引用）
- 系统提示：居中细体（护轨拦截、连接错误、会话切换提示）

AI 流式状态：
- 等待首个块：显示"思考中"加载指示（三点跳动动画）
- 接收中：逐块拼接，末尾跟随闪烁光标
- 完成：光标消失，消息固化

每条 AI 消息底部操作：
- 「复制」按钮（复制纯文本）
- 可选：「重新生成」按钮（用相同 message 重新发起）

错误状态：
- SSE 连接失败：消息位显示"连接中断，点此重试"
- 护轨拦截：显示"输入包含敏感内容，已被安全护轨拦截"

### 4.4 快捷方向区

4 个胶囊按钮（空会话时显示为卡片，有消息后收为输入区上方一行），点击直接发送预设问题：
1. 学习路线图标，"规划编程学习路线"
2. 灯泡图标，"给我项目学习建议"
3. 文档图标，"求职全流程指南（简历/投递）"
4. 问号图标，"高频面试题与技巧"

### 4.5 输入区

要素：
- 多行文本框（自适应高度，`Shift+Enter` 换行，`Enter` 发送）
- 「发送」按钮：流式进行中变为「停止」按钮，点击中断当前流式（前端关闭 EventSource）
- 占位符："问问编程学习或面试的问题…"
- 可选：字数提示

交互：
- 空消息不可发送（发送按钮 disabled）
- 流式中输入框可继续输入，但主按钮为「停止」

## 5. 交互流程

1. 首次进入 → 创建默认会话（`memoryId=1`），或从 `localStorage` 恢复上次会话列表与当前会话
2. 空会话 → 显示欢迎语 + 4 方向快捷卡
3. 用户输入 → 点发送 → 用户消息立即上屏 → 调 `GET /ai/chat` → AI 流式逐块渲染
4. 流式完成 → 消息固化，可复制/重生成
5. 切换会话 → 从 `localStorage` 加载该 `memoryId` 历史
6. 新建会话 → 新 `memoryId` → 空白对话区

## 6. 视觉风格

- 调性：科技感、专业、克制，偏开发者审美
- 配色：深色为主。主色科技蓝/紫（`#6366f1` 或 `#3b82f6`），深底（`#0f172a` / `#1e1b4b`），辅助阿里云橙（`#ff6a00`）做点缀，中性灰（`#94a3b8`）用于次要文本。浅色模式柔和灰白底
- 字体：无衬线（Inter / 系统默认），代码等宽（JetBrains Mono / Fira Code）
- 圆角：中等（8-12px），用户/AI 气泡视觉区分
- 动效：流式打字光标、消息淡入、按钮 hover 微动效，避免过度
- 代码块：深色背景 + 语法高亮 + 一键复制按钮
