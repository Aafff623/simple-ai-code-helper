# Deliver · 交付与交接（场景 A）

场景 A：单任务交接。每个实施任务产出一份 handoff 文档，供 Review 与接手者快速进入上下文。

## handoff 文档位置

`docs/output/handoff/{theme}/{task}.md`

一任务一文件，文件名用 kebab-case 任务标识。

## handoff 文档结构

```
## 任务
<!-- 一句话说明做什么，关联 Issue #N -->

## 上下文
<!-- 相关文件、模块、依赖的现有状态 -->

## 变更
<!-- 改了什么，为什么这么改 -->

## 验证
<!-- 怎么验证生效：测试 / 复现脚本 / 手动步骤 -->

## 接手引导
<!-- 下一个人怎么继续：入口文件、已知风险、待办 -->
```

## 交付前自检

- 变更可追溯到任务目标，无无关改动
- 验证步骤可独立复现
- 无密钥、无调试残留入库
